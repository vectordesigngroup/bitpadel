# Templates

| File | Use |
|---|---|
| `financial-model.csv` | Blank model. Open it in any spreadsheet app; rows marked INPUT start at 0, rows marked CALC are formulas. Replace every input with your own local quotes. |
| `founding-member-page.html` | A founding-member interest page with **no prices**. Replace `[CLUB NAME]`, `[CITY]` and the other brackets. |
| `event-run-of-show.md` | Minute-by-minute plan for a workshop, meetup or tournament night |
| `sponsor-one-pager.md` | Fill-in-the-blanks sponsor sheet (sponsorship, not investment) |
