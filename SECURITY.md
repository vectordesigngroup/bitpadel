# Security

BitPadel is a prototype. The supported line is the default branch (`main`) only. Older commits are not maintained as separate releases.

## Reporting a vulnerability

Report security issues in private through GitHub Security Advisories:

<https://github.com/vectordesigngroup/bitpadel/security/advisories/new>

Do not open a public issue, pull request, or discussion for a security report. This project does not publish a personal email address for vulnerability reports.

Include what you found, how to reproduce it, and the commit you tested. Please give the maintainers time to respond before any public write-up.

Private vulnerability reporting is a GitHub repository setting. This file is the contact method. Turning that setting on is separate from this document and is not done by a pull request.
