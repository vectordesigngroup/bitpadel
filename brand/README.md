A deliberately neutral look so the templates render nicely out of the box. **Replace it with your own club's name, logo and colors.**

|---|---|---|
| Slate night | `#0F172A` | Background |
| Surface | `#1E293B` | Cards/sections |
| Text | `#F8FAFC` | Body text |
| Muted | `#94A3B8` | Secondary text |

Font: Inter (or any system sans-serif).

Files: `logo-placeholder.svg`, `bitpadel.css`.

You can use these placeholder files while you build, but don't use the BitPadel name or logo as your own club's brand; see [`../TRADEMARKS.md`](../TRADEMARKS.md).
